# Paper result records

- `nb101/` contains the 10-run main experiment, component-ablation records, DAE-EDA records, and the compact curve files used for the ablation figure.
- `nb201/` contains the 10-run results for CIFAR-10, CIFAR-100, and ImageNet-16-120.
- `nb301/` contains the 10-run NAS-Bench-301 result records and curve data.

Downloaded benchmark datasets are not included. The commands required to reproduce these records are listed in the repository README.
